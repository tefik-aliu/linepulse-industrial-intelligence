# Proof-of-work plan

LinePulse is built to produce inspectable evidence rather than a collection of technology names.

## Public evidence

- Working factory simulation
- OEE, scrap, downtime, MTBF and MTTR calculations
- Explainable pressure-drift, micro-stop and defect-cluster alerts
- Simulated dependency failure that changes readiness
- Downloadable Excel shift report
- API documentation
- Prometheus metrics
- Automated Python and browser testing
- CI history
- Issues, branches and pull requests for future work

## Honest boundaries

Version 0.1 is a synthetic production environment. It does not claim:

- connection to a real PLC or MES,
- validated production-scale performance,
- predictive maintenance accuracy,
- production-grade authentication,
- safety-critical decision authority.
